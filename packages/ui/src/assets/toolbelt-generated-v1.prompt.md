# Toolbelt generated icon — version 1

Generated using the built-in image generation tool, with transparent background enabled.
The full-resolution generated master is `toolbelt-generated-v1.png`.
The app uses the 256 px derivative, `toolbelt-generated-v1-ui.png`.
Browser PNG sizes and the app derivative are produced by `python3 scripts/render-icons.py`.
The other tool icons keep their existing artwork.

## Generation prompt

Use case: logo-brand. Generate ONE finished app icon image for Toolbelt, a premium browser extension that brings useful everyday tools into one place. User rejected conventional tool pouch drawings, generic small glyphs and the previous icon family. Create a distinctly different, beautifully simple main product icon ONLY. Art direction: a sculptural continuous folded ribbon forming a confident geometric lowercase t / interlocking belt-loop symbol, one strong unmistakable silhouette, two broad interlocking planes, elegant negative space. Rich midnight cobalt with a restrained luminous ice-blue edge and softly lit satin material. Sophisticated and calm, meticulously balanced, subtle dimensionality rather than glossy toy rendering. It should feel like a carefully designed premium productivity app icon. Deliver a single centered rounded-square app tile, nearly filling the square canvas with small even transparent outer margins and transparent corners. Within the midnight tile place the bold pale icy-blue ribbon symbol with generous internal breathing room, optimized to remain clear at 16–32 pixels. Front-facing orthographic view. No lettering, no wordmark, no text, no mockup, no presentation board, no multiple concepts, no tiny details, no pouch, no toolbox, no sparkles, no gold, no glass, no dramatic shadow outside the tile. High-resolution square production asset with genuine alpha transparency outside the rounded-square tile.
